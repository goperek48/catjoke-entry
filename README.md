One line about a cat, for make.fun's "The One-Line Cat Joke That Lands" bounty ($2, winner takes all). A judge model reads the jokes two at a time and keeps the funnier one until one joke is left standing.

The joke: "I bought my cat a $200 bed. He sleeps in the box it came in, on my laptop, during my job interview."

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only) validates the joke — one line, under 200 characters — and writes it to `/output/entry.txt` with no trailing newline.
